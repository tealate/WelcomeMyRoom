# Fill棒の面に合わせた軸方向

Fill棒は従来どおり、視線の候補セルを含むRegionとオフハンドのブロックを使います。`axis` 状態を持つ素材では、選ばれたRegionと視線の交点から触れた面を判定し、範囲全体を同じ軸方向で埋めます。1ブロック幅のRegionでも、候補セルの中心だけで面を決めません。

| 触れた面 | `axis` | 原木の切り口 |
| --- | --- | --- |
| 上・下 | `y` | 上下 |
| 東・西 | `x` | 東西 |
| 南・北 | `z` | 南北 |

対象は通常・樹皮付き・樹皮を剥いだ各種原木と木材、真紅・歪んだ幹と菌糸、竹ブロック、干草の俵、骨ブロック、クォーツ／プルプァの柱、玄武岩、深層岩です。軸状態を持たない素材はこれまでどおり標準のブロック状態でFillします。階段やかまどなど、`axis` 以外の方向プロパティは今回の対象外です。

視線が選択されたRegionを通らない場合は、従来の候補セルからの面判定を使います。Fillが成功したときだけ対象Regionを削除します。

生成元は `tools/build_space_editor_stage2.py`。再生成は `python -B tools/build_space_editor_stage5.py`。ライブ環境では `/reload` で反映します。Stage05 GameTestでは6面と代表的な軸ブロック、Fill後のRegion削除を確認します。
